# ¿Qué es pip?
Es un administrador de paquetes (librerías) que se utilizan habitualmente.


## Instalar paquete

```sh
pip install requests
```  

## Listar librerías que tenemos instaladas

```sh
pip list
```

## Ver info de la librería

```sh
pip show requests
```  

## Desinstalar paquete

```sh
pip uninstall requests
```

# Trabajando con entornos

## Creamos entorno virtual

```sh
py -m venv .entorno
```

## Activamos el entorno

```sh
.entorno\Scripts\activate
# (.entorno) C:\...
```
